# OOPS CodeVault

A standalone, searchable C++ Object-Oriented Programming (OOPS) practical library containing 10 practical questions, complete source code, algorithms, sample input/output, and practical exam viva questions.

## Features
- **10 Core OOPS Practicals**: Class design, operator overloading, inheritance hierarchies, matrix ADT, multiple inheritance constructor order, file streams, class templates, associative containers (`std::map`), and ATM real-time application exception handling.
- **Matched Sibling UI**: Recreates the design language, typography, dark/light theme, and layout of [DSA CodeVault](https://dsa-codevault.vercel.app/).
- **Syntax-Highlighted Code**: JetBrains Mono with Prism.js C++ highlighting.
- **Copy & Download**: Working one-click source copy and original `.cpp` file download.
- **Search & Filter**: Search by question number, title, concept, class name, or keyword.
- **Exam-Ready Content**: Sequential step-by-step algorithms, real compiled outputs, and high-yield viva Q&A pairs.

## Tech Stack
- React 18, TypeScript, Vite
- Tailwind CSS (Light & Dark modes)
- React Router v6
- Prism.js & Lucide React
- Vercel Static Hosting
